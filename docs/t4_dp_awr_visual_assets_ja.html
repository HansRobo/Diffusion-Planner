0. まず、画像から言ってよいことを固定する

A/B/Cは品質順位ではなく、検証対象の違いである。Aは正式学習cacheの局所選択、Bはsource policyの候補coverage、Cはevaluator単体の反応を示す。全体性能の改善は、どの画像からも単独では結論できない。

A · FORMAL REPLAY

学習へ実際に入ったK=10

epoch-1 frozen replayからtrajectory、reward、weightを直接読む。collision / road-borderの局所contrastを検証できる。

B · COVERAGE

source Original DPのK=16

候補が一本へcollapseしていないかを診断する。学習後checkpointの改善とは読まない。

C · METRIC PROBE

構造化counterfactual

同じ実scene geometry上で意図的なstop / go / shortcutを与える。model outputではなくreward unit testである。

全体改善の判定：選定checkpointとsourceを、同じ46,068 held-out scene・同じseed・同じevaluatorでpaired評価し、平均scene score gainのbootstrap CI下限>0を主条件にする。hard safety、ADE/FDE、重要sliceは同時に公開する診断内訳。

HONEST SELECTION

改善と回帰を8 roleで選ぶ

collision / road-borderの回復と新規発生に加え、stopped受益とlane-change最大ADE回帰を明示的に含める。残枠はPareto / 最大gain・regressionで埋め、同じsceneを重複させない。

自動生成先：t4_conference_assets/final_validation/。各sceneにPNG / GIF / JSONを置き、JSONにはfull-validation上の選定理由、reward全成分、ADE/FDE、+1 alignment、rear-axle OBB契約を残す。全PNG/GIFタイトルとJSONへ PAPER-ALIGNED MEAN SCORE PASSED または NOT PROMOTED · MEAN GAIN UNPROVEN を固定し、局所改善図だけが単独転送されても採用可否を誤読できないようにする。
